Unggah Peta Jalan Hidup — Tanpa Login

Mahasiswa memasukkan NIM, nama sesuai SIAKAD, dan email aktif. Tidak perlu membuat akun atau memasukkan password.

Isi NIM, nama, email, lalu pilih file.

Privasi: file seharusnya disimpan pada bucket privat Supabase melalui layanan server yang memvalidasi unggahan. Jangan memasukkan service-role key ke dalam HTML.

Petunjuk dan batas data

  • Daftar mahasiswa merupakan data awal dari file SIAKAD yang diberikan.
  • Daftar pada halaman ini tidak otomatis berubah saat SIAKAD berubah.
  • Unggahan tanpa login harus melalui Edge Function yang memvalidasi NIM, nama, email, tipe file, dan ukuran.
  • Jangan membuat bucket publik atau membuka Storage Policy untuk semua orang.

Halaman ini tidak terhubung langsung ke SIAKAD. Pengunggahan menggunakan Supabase Edge Function dan Storage privat.
